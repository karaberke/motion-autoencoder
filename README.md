# Motion autoencoder coursework

Submitted Fall 2026 Generative Visual Computing coursework exploring a convolutional autoencoder for motion data and motion editing. The course supplied scaffolding and a data-loading workflow; this repository does not claim that every TODO or experiment was completed or validated.

## Source and data

This public copy contains the submitted Python and notebook source. Notebook outputs, generated videos, cached motion data, and the submitted report are omitted. The notebook describes the required CMU Mocap data and expected local cache layout. Its output cells were cleared for public sharing; the code cells were retained.
